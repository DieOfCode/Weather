# Weather

Учебное погодное Android-приложение с гибридным UI:

- XML: `MainActivity`, `NavHostFragment`, navigation graph, toolbar;
- Compose: содержимое погодных экранов;
- первая итерация использует статические данные и Compose Preview.

## Первый этап

Откройте `WeatherScreen.kt` и запустите Preview `WeatherScreenPreview` или
соберите приложение командой:

```shell
./gradlew assembleDebug
```
